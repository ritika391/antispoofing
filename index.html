Implementation

Source Code

Production-grade PyTorch implementation with clean, documented modules.

src/model.py 
# FaceGuard — MobileNetV2 Anti-Spoofing Model

import torch
import torch.nn as nn
from torchvision.models import mobilenet_v2, MobileNet_V2_Weights

class SEBlock(nn.Module):
    """Squeeze-and-Excitation — channel-wise texture attention."""
    def __init__(self, channels, reduction=16):
        super().__init__()
        self.se = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
            nn.Linear(channels, channels // reduction, bias=False),
            nn.ReLU(inplace=True),
            nn.Linear(channels // reduction, channels, bias=False),
            nn.Sigmoid(),
        )
    def forward(self, x):
        return x * self.se(x).view(x.size(0), x.size(1), 1, 1)

class FaceGuardModel(nn.Module):
    """MobileNetV2 + SE Attention + Custom Head — 3.4M params."""
    def __init__(self, num_classes=2, pretrained=True):
        super().__init__()
        backbone       = mobilenet_v2(weights=MobileNet_V2_Weights.IMAGENET1K_V1)
        self.features  = backbone.features
        self.se        = SEBlock(1280)
        self.avgpool   = nn.AdaptiveAvgPool2d(1)
        self.head      = nn.Sequential(
            nn.Linear(1280, 512, bias=False), nn.BatchNorm1d(512),
            nn.GELU(), nn.Dropout(0.4),
            nn.Linear(512,  128, bias=False), nn.BatchNorm1d(128),
            nn.GELU(), nn.Dropout(0.3),
            nn.Linear(128, num_classes),
        )
        self._freeze_backbone()

    def _freeze_backbone(self):
        for p in self.features.parameters(): p.requires_grad = False

    def forward(self, x):
        x = self.features(x)     # (B,1280,7,7)
        x = self.se(x)            # channel reweighting
        x = self.avgpool(x)       # (B,1280,1,1)
        x = torch.flatten(x, 1)   # (B,1280)
        return self.head(x), x     # logits, features

About the Project

Research Context

Face anti-spoofing is a critical component of any biometric authentication system. Without liveness detection, face recognition systems are trivially defeated by holding a photograph in front of the camera.

This project implements a state-of-the-art detection pipeline using MobileNetV2, a lightweight architecture designed for mobile deployment, extended with squeeze-and-excitation attention to emphasize texture-discriminative feature channels.

"The key insight is that real faces exhibit micro-texture patterns (pores, skin reflectance, sub-surface scattering) that are not reproduced by print or screen attacks."

We use Focal Loss to handle class imbalance, JPEG compression augmentation to simulate print/replay artifacts, and EER-based threshold calibration for production-grade performance.
